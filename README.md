# 🧮 Interactive Number Manager (Java)

Um sistema em Java feito no console para gerenciar e analisar números de forma simples e interativa.

Esse projeto foi desenvolvido com o objetivo de praticar lógica de programação, organização de código e interação com o usuário — evoluindo de um código simples para algo mais estruturado e próximo de um sistema real.

---

## 🚀 O que esse projeto faz?

Com ele, você pode:

✔ Adicionar números à lista  
✔ Visualizar os números com identificação de par/ímpar  
✔ Ver estatísticas completas:  
- Soma  
- Média  
- Maior valor  
- Menor valor  
- Quantidade de pares e ímpares  

✔ Remover números:
- Por posição (índice)
- Ou limpar toda a lista com confirmação  

✔ Navegar por menus interativos com validação de entrada  

---

## 🧠 O que foi praticado aqui

Durante o desenvolvimento, foram aplicados conceitos importantes como:

- Métodos (funções bem separadas e reutilizáveis)
- Estruturas de repetição (while, for)
- Estruturas condicionais (if, switch)
- Manipulação de listas (ArrayList)
- Tratamento de erros (try/catch)
- Validação de entrada do usuário
- Organização e legibilidade de código

---

## 💡 Destaque do projeto

Um dos pontos principais foi a criação de um sistema de entrada seguro, que impede o programa de quebrar caso o usuário digite algo inválido.

Além disso, o menu foi estruturado de forma interativa, permitindo navegar entre funcionalidades sem encerrar o programa.

---
